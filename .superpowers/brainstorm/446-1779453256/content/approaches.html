How should we execute the full redesign?

All 3 preserve existing functionality (ReactFlow, xterm, TanStack Query, WebSocket). This is about the visual & motion layer.

A

Design System First (Recommended)

Build the Antigravity Glass component library first — AuroraOrb, GlassCard, ParticleField, NeonBadge, SplineHero, OrbitalTimeline — then systematically apply across all 16 pages. Every page shares the same tokens. Single globals.css overhaul.

Pros

  • Pixel-perfect consistency
  • Easy to update theme-wide
  • Each page is fast to assemble

Cons

  • Longer before first page ships
B

Shell → Hero Pages → Remaining

Redesign AppShell + globals.css first (every page benefits immediately), then Dashboard, Workflows, Executions, AI Workflow, Knowledge Graph, then the rest. Ship visible wins fast.

Pros

  • Visible progress immediately
  • Test look on real pages early

Cons

  • Some inconsistency mid-execution
C

globals.css + Token Overhaul Only

Upgrade the design tokens, shadows, glass classes, and motion variants in globals.css. No new components — just make the existing ones look dramatically better. Fastest path.

Pros

  • Zero risk to functionality
  • Complete in one session

Cons

  • Can't add Spline, Orbital, particles
  • Less "wow factor"
